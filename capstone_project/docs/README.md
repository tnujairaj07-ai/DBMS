# LearnLink Documentation Hub

Welcome to the documentation repository for **LearnLink: An Explainable Skill-Based Academic Project and Mentor Allocation Management System**.

This folder is designed to track everything related to the project: architecture, database design, progressive phase-by-phase implementation checklists, and date-wise development logs.

---

## 🎯 How to Use This Documentation

1. **Before Starting Any Phase**: Check [**`PHASES_AND_CHECKLIST.md`**](./PHASES_AND_CHECKLIST.md) to understand the scope and deliverables.
2. **When Writing Backend or DB Queries**: Reference [**`DATABASE_SCHEMA.md`**](./DATABASE_SCHEMA.md) for precise table names, column constraints, triggers, and stored procedures.
3. **When Checking Architecture & Endpoints**: Consult [**`ARCHITECTURE.md`**](./ARCHITECTURE.md).
4. **After Finishing Any Session or Task**: Update [**`PROJECT_LOGS.md`**](./PROJECT_LOGS.md) with date, what was accomplished, and next goals.
